Replace the default WordPress login URL with a custom endpoint and customize the login logo.

== Description ==

Custom Login Endpoint allows site owners to access the WordPress login screen through a custom URL while restricting direct anonymous access to wp-login.php.

Need custom development?

Visit [FuturisticIT]( https://futuristicit.com/contact-us/) for WordPress, WooCommerce and other services.

Features:

* Custom login endpoint
* Custom login logo
* Redirect direct anonymous access
* Lightweight and easy to configure

== Installation ==

1. Upload the plugin through Plugins > Add New.
2. Activate the plugin.
3. Go to Settings > Secure Login.
4. Configure your custom login endpoint.

== Frequently Asked Questions ==

= Does this improve security? =

This plugin changes how visitors access the login page. It should not replace strong passwords, two-factor authentication, or other security measures.

= What if my custom URL stops working? =

Visit Settings > Permalinks and click Save Changes to flush rewrite rules.
